## Statement of Usage
We declare that Artificial Intelligence (AI) tools were utilized during the development of this project. The AI acted as a pair-programming assistant, contributing to the following areas:

1. **Architecture & Design:** Suggesting and refining structural design patterns (e.g., State, Observer, Factory, Singleton, Memento, Object Pool).
2. **Implementation:** Assisting in writing boilerplate C++ code, engine subsystems, algorithms (e.g., AABB collision), and gameplay logic.
3. **Debugging & Refactoring:** Identifying bugs, fixing logic flaws, and optimizing code structure for maintainability.
4. **Documentation:** Generating report drafts, logging task history, and formatting class diagrams.
5. **Submission Preparation:** Refreshing and extending all submission documents with complete evidence trails and scope specifications.

## Tools Used
- **Antigravity** (Google, Gemini-based) — the primary agentic coding tool used across most of the project's history: implementing engine subsystems and design patterns, enemy/entity work, level content, weekly report drafting, and the majority of the git history's commits.
- **Claude Code** (Anthropic) — introduced from 2026-08-18 onward for intensive defect remediation and submission preparation: executing the complete R1–R21 defect-batch remediation plan (Aug 18 – Sep 2), implementing subsystems shipped in that span (EntityCatalogue registry, dynamic lighting shader, real map editor with custom-level save/load, attract-mode idle replay, LOAD GAME menu with slot picker), fixing and completing Endless Mode with procedural boss arenas and the level-solvability oracle, writing and running the `verify_*` regression and guard test suite, and generating/expanding all submission documents (report, feature list, member contributions, testing checklist, AI usage declaration, demo video checklist) directly from codebase git logs and evidence trails rather than from blank pages.

## Academic Integrity
While AI assisted in the development, we carefully reviewed, tested, and integrated all AI-generated code. We understand the underlying logic of the submitted system and take full responsibility for its correctness, architecture, and behavior. The custom game logic, level design, and system integration were actively directed, guided, and verified by the human developers.
