# Lane K — the 1-3 Bowser fight, observed live.
#
# Why this exists: AGENTS.md directive 9/10. tests/verify_r21_boss_combat.cpp
# drives the fight through the real collision pipeline against level_3's own
# tilemap, but a harness does not prove PlayingState ever runs it. This does.
#
# TEMPORARY state, restored and verified afterwards:
#   saves/slot_1.json   — Fire Mario, level id 3, on the right-hand ledge at tile
#                         188 — the last bridge column, four tiles right of
#                         Bowser (~1.2s of walking at BOSS_BOWSER_SPEED 55) so
#                         INVINCIBLE lands before his first contact, and two
#                         tiles short of the bridge_axe at (190,19), which a
#                         take from tile 191 walked into: that chopped the bridge
#                         and deleted him on the spot, which is defect 3. MAIN MENU > LOAD GAME > SLOT 1 restores level,
#                         form and position (PlayingState::loadFromSlot), which
#                         is how the arena is reached WITHOUT the level_3.json
#                         spawnPoint override tests/scripts/verify_r12_bridge_axe.txt
#                         uses — that file belongs to another lane this batch.
#                         The alternative, walking 180 tiles from the level's own
#                         (3,19) spawn via the Fire Flower at tile 66, failed on
#                         the first attempt exactly as R9/R12/R16's blind long
#                         runs did.
#   saves/config.json   — debugMode true, for the F-row cheats. The shipped
#                         default is off; the game rewrites this file on exit, so
#                         it is reset AFTER the run, not before it.
#   saves/progress.json — levels 0 and 1 completed, so the world map is
#                         consistent with a save that claims to be in 1-3.
#
# Two timing facts this script is built around, both learned the hard way:
#   - Bowser closes on the player within a second of the load and every contact
#     costs a form, so INVINCIBLE (F3) has to be on before he arrives or the run
#     is Super Mario with no fireballs by the time F is pressed. A take with the
#     cheats 1.2s late recorded exactly that: one contact, then six dead F
#     presses and no fireball spawned at all.
#   - `shot` saves a 1280x720 PNG, which costs real time that the fixed-timestep
#     accumulator then hands to the simulation. Four screenshots between the
#     fourth fireball and the first jump burned the whole 3s stagger, so the
#     stagger window below has none in it.
#
#   ./build_lane_k/SuperMarioGame --script tests/scripts/verify_r21k_bowser_fight.txt
#
# Screenshots land in saves/shots/.
