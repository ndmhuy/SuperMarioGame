# R5 (D8 / A-10) live run: the collision and physics dispatch refactor.
#
# Every dynamic_cast in CollisionResolver.cpp and PhysicsEngine.cpp was
# replaced by a virtual hook on the entity (Item::onPlayerTouch,
# Block::onCharacterTouch, Enemy::onPlayerTouch, Enemy::isHazardToEnemies,
# Entity::isOnGround / isPhysicsDriven / reversesAtLevelEdge / onTileImpact /
# ridesConveyors / applyHorizontalControl / beginPhysicsFrame, and
# Player::getRunSpeed). Nothing here is new behaviour, so the point of the run
# is that the *existing* behaviour still happens through the new dispatch.
#
# What this script is meant to exercise on World 1-1, in order:
#   - Character::applyHorizontalControl: run right under LShift+D and actually
#     accelerate (the whole locomotion body moved out of PhysicsEngine).
#   - Enemy patrol + Entity::isPhysicsDriven: the Goomba at tile 12 walks left
#     to meet the player.
#   - Enemy::onPlayerTouch returning false -> the resolver's generic stomp:
#     score goes up and the Goomba flips (a flipped enemy then reports
#     isPhysicsDriven() == false and falls under its own animation).
#   - resolveEntityVsTile through Entity::isOnGround: the staircase at tiles
#     25-27 has to be climbable, which is the wall-slide/jump interaction the
#     resolver's Character branch guards.
#
# HONESTY NOTE: --script replays fixed input with no positional feedback, so
# whether a given jump lands on the Goomba drifts a little run to run. Read the
# screenshots rather than assuming.
#
#   ./build/SuperMarioGame --script tests/scripts/verify_r5_collision_dispatch.txt
