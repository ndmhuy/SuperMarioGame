# Two defects, one level (World 1-1 / assets/levels/level_1.json):
#   1. MovingPlatform::update() never called Block::update(), so the
#      platform's animator never advanced. The platform's OWN kinematic
#      motion (the part that was already correct) is what a screenshot can
#      actually show moving between two shots; the shipped animation is a
#      single looping frame ({"half_platform_long", 0.15s}), so the specific
#      "animator no longer frozen" effect has no photographable difference —
#      that half of the fix is covered by verify_2a_platform_anim_and_spiny_egg
#      (which drives Animator::isDone() directly) rather than by a screenshot.
#   2. Spiny::isEgg was unreachable. SPEC 6.1: Lakitu "drops Spiny eggs every
#      4s" and Spiny "walks on ground after hatching from egg". This run
#      flies to World 1-1's Lakitu (tile 175,11) and bursts screenshots
#      across its 4s throw interval to catch a dropped Spiny still showing
#      the egg sprite (spiny_ball_0/1) before it lands and hatches into the
#      walking sprite (spiny_move_left_0/1).
#
# PRECONDITION: "debugMode": true in <repo root>/saves/config.json (the F-key
# cheats below are inert otherwise — DebugCheats::isArmed()). NOCLIP (F8) is
# a PLAYER-only cheat (gravity/collision on the player); it does not affect
# Lakitu or the Spinies it drops, which still fall and hatch under ordinary
# physics. INVINCIBLE (F3) and INFINITE LIVES (F4) are just so a Spiny's
# stomp-immunity/damage does not end the run before the interval elapses —
# neither one touches the egg/hatch logic under test.
#
