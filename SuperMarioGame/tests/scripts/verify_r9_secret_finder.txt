# through the real main() path: menu -> Start -> character select -> world map ->
# 1-1 -> down the warp pipe at tile 98 -> level_1_sub.json -> reveal the five

# TWO TEMPORARY EDITS THIS SCRIPT NEEDS, AND WHY
# ----------------------------------------------
# Neither is committed; both were reverted and `git diff` confirmed clean before
# the F1 commits landed. They are recorded here so the run can be reproduced.
#
#  1. level_1.json  "spawnPoint": {"x": 98, "y": 16}
#     Mounting the warp pipe blind is the part R16 needed 13 attempts to land
#     once. Pipe::checkWarp wants the player's feet within 4 px of the pipe rim
#     and their centre inside its 64 px width; spawning one tile above the pipe
#     drops them onto the rim, and a single `hold S` warps. This replaces luck
#     with geometry and changes nothing about what is being tested.
#
#  2. level_1_sub.json  the two goombas (13,17) and (39,17) removed
#     Small Mario dies on contact and the vault has no mushroom, so a blind
#     traverse of the block row loses all three lives to the goombas before the
#     fifth block. They are shipped content and are back in the committed file;
#     removing them for the run isolates the hidden-block mechanic from a
#     traversal problem that has nothing to do with it.
#
# HOW IT FINDS THE BLOCKS
# -----------------------
# Hidden blocks sit at (13,14), (21,14), (29,14), (37,14) and (45,14) — every
# other gap in the vault's "?c?" row. The pipe drops the player at (5,16); the
# timed `hold D` legs below walk 8 tiles at a time (150 px/s, ~1.35-1.60 s per
# leg after the 1000 px/s^2 ramp) and jump three times per target about 0.8 tile
# apart, which covers the one-tile window either side of the drift. The two
# sweeps at the end re-cross the whole row at a different phase and pick up
# whatever the timed passes missed — in the observed run the fifth block was
# found during the westward sweep.
#
# HONESTY NOTE: this is still fixed input with no positional feedback. The timed
# legs found four of five blocks; the sweeps are what made it five. If a run ends
