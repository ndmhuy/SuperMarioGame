# R21 Lane D - Defect 7 part 2: a PROCEDURALLY GENERATED boss encounter.
#
# What this has to show, in the running game:
#   * a Hard procedural level builds a real arena - lava trench, bridge, posts,
#     an axe - instead of dropping a bare Bowser onto the flat exit apron;
#   * PlayingState adopts him (findActiveBoss() is now called on the procedural
#     path), so the HUD health bar, the boss name, the stagger hint and the
#     bowser_boss_battle music all engage;
#   * the camera locks to the arena - "[PlayingState] Boss arena locked" on
#     stdout, and the view stops scrolling in the screenshots.
#
# For a 200-wide Hard level the arena lands at tiles 166-178, so the run is
# ~166 tiles of Hard procedural terrain. IMMORTAL (F2) and INVINCIBLE (F3) are
# on for the trip so a pit or a Hammer Bro does not end the take before the
# arena; neither touches the boss wiring being observed.
#
# PRECONDITION: "debugMode": true in saves/config.json (F2/F3 do nothing
# otherwise). Restore that file afterwards.
#
#   ./build_r21_lane_d/SuperMarioGame --script tests/scripts/verify_r21d_procedural_boss.txt
