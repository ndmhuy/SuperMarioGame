# Phase 3A screenshot catalogue -- the showcase walkthrough.
#
# Drives a single custom level (assets/levels/custom/report_showcase.json)
# end to end: 11 of the 13 catalogue enemy types, the full Small->Super->
# Fire and Super->Cape power-up chain plus Mini/Star/Mega, the remaining
# items and every block type, the minimap toggle, a Memento time-rewind,
# an achievement toast (stomp), and the flagpole+castle ending in
# VictoryState. The level is authored directly as JSON, not built in the
# in-game editor: scripted mouse/key events never reach
# ImGui::SFML::ProcessEvent (Game::run(), src/Core/Game.cpp), so neither the
# editor's ImGui palette nor the debug console's `spawn` command is
# reachable from a --script file. tests/scripts/verify_r21i_lighting_daynight.txt's
# header documents the same direct-JSON-authorship workaround for the same
# reason.
#
# Precondition -- build the level once, from SuperMarioGame/, before
# running this script (regenerates assets/levels/custom/report_showcase.json):
#   python3 tools/report_shots/build_showcase_level.py
#
# Precondition -- saves/config.json must have "debugMode": true so the
# Immortal cheat (F2) is armed: it turns a would-be-fatal hit into a life-1
# Small-state rescue instead of Game Over (Player::loseLife), while leaving
# ordinary Fire/Cape/Super power-downs (not deaths) completely alone -- see
# Player::takeDamage/powerDown -- which is exactly what lets one continuous
# walk demonstrate every power-up form without ever restarting.
#
#   ./build/SuperMarioGame --script tests/scripts/report_showcase_walk.txt
#
# Screenshots land in saves/shots/.
