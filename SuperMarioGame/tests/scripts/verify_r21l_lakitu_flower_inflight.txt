# R21 Lane L — photograph the Fire Flower ITSELF leaving the Lakitu.
#
# The companion script (verify_r21l_lakitu_flower.txt) proves the drop by its
# effect: Small Mario at TIME 272 becomes FIRE Mario at TIME 271 with exactly
# +1000 score, and never again for the next 37 seconds. What it cannot show is
# the flower, because the drop starts 148px above the player's head and is
# collected in under half a second — shorter than the gap between frames.
#
# So this run repeats the same approach and then slows the SIMULATION with
# Debug > Cheats' time scale (F11 steps 1x - 0.5x - 0.25x - 0.1x) just before
# the drop is due. The flower's fall stretches from ~0.4s to ~1.7s of real time,
# which the 0.6s sampling below catches. The time scale is a rendering/stepping
# aid: it multiplies the dt every timer in the game sees, the flower interval
# included, so it changes WHEN the drop happens in real seconds and not whether.
#
# WHY THE TIMINGS ARE WHAT THEY ARE (level clock, from the shipped level_1):
#   t=0     spawn tile 98.5 (x~3152); the level's only Lakitu at tile 175
#           (x=5600), so they start 2448px apart.
#   t~5     cheats armed, the player flies east under NOCLIP; the two close at
#           250 px/s (150 walk + 100 Lakitu tracking).
#   t~8     separation reaches ENGAGE_RANGE_X (1280) — the clock starts HERE,
#           not at level load, which is the whole point of the engagement gate.
#   t~25    F11 twice: 0.25x. ~4s of engaged time is still owed, i.e. ~16s real.
#   t~29    FLOWER_DROP_INTERVAL elapses and the flower falls.
#
# PRECONDITION: "debugMode": true in saves/config.json. Restore it to false
# afterwards — Game::shutdown() persists it and the shipped default is off.
#
# Run with (from SuperMarioGame/):
#   ./build_lane_l/SuperMarioGame --script tests/scripts/verify_r21l_lakitu_flower_inflight.txt
