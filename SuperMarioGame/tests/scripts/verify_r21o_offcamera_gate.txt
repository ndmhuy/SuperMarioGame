# R21 Lane 2D — the off-camera entity update gate, observed in a real Endless run.
#
# WHAT THIS HAS TO SHOW
# ---------------------
# Endless Mode never discards a chunk it has appended, so m_entities only grows:
# extendEndlessLevelIfNeeded() splices 100 fresh tiles of content in every time
# the player gets within 40 tiles of the end, and before this change every one
# of those entities called update() every frame for the rest of the run, however
# far behind the camera it had been left.
#
# The census on each "appended chunk" line is the evidence. Read stdout:
#
#   entities live N, thinking T, frozen off-camera F      (N == T + F)
#
# `live` is exactly what the ungated loop used to update every frame, so the
# before/after comparison comes out of ONE run rather than two builds. As the
# run gets longer, `live` climbs and `thinking` should not.
#
# It also has to show that the run still WORKS: the player keeps moving right,
# chunks keep appending, and nothing the gate froze comes back wrong. A gate
# that freezes something the player notices is worse than no gate.
#
# WHY THE CHEATS ARE ON
# ---------------------
# NOCLIP (F8) is the traversal aid, and it is the one that makes this script
# work at all. Two earlier attempts held D and tapped W for four minutes and
# covered 132 m and 97 m: a tapped W is a minimum-height jump, and the run wedged
# against the first two-tile pipe with a question block over it. Not one chunk
# appended, so the census printed nothing. NOCLIP passes through solids with
# gravity off, so the player simply travels right at run speed and the
# lookahead is reached on schedule.
#
# NOCLIP changes the PLAYER's tile collision and nothing else. What is being
# measured here is the entity population the chunk splicer produces and how much
# of it thinks each frame; the gate is measured against the camera, and the
# camera follows the player either way. IMMORTAL (F2), INVINCIBLE (F3) and
# INFINITE LIVES (F4) are belt and braces for an unattended run.
#
# PRECONDITION: "debugMode": true in saves/config.json. Restore it afterwards.
# The F-row cheats are behind that flag (PlayingState::handleInput), and without
# them a first attempt at this script died in the second pit, respawned at the
# start and covered 132 m in four minutes — never reaching the 160-tile
# lookahead, so not one chunk appended and the census printed nothing.
#
#   ./build/SuperMarioGame --script tests/scripts/verify_r21o_offcamera_gate.txt
#
