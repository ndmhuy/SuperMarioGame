# R10 guard verification (F5 attract mode, SPEC 10.2), run with
# SUPERMARIO_ATTRACT_IDLE_SECONDS=3 so both guards can be checked without a
# literal 30s wait each:
#
#  1. Debug console open: idling past the threshold while the console is up
#     must not start the demo (MenuState::update() checks
#     DebugConsole::isVisible() before touching m_idleTime — see MenuState.cpp).
#  2. Load Game picker (Page::Load, added in R8): idling past the threshold
#     while sitting in the picker must not interrupt it (MenuState::update()
#     only checks the idle timer on Page::Main).
#
#   SUPERMARIO_ATTRACT_IDLE_SECONDS=3 ./build/SuperMarioGame --script tests/scripts/verify_r10_attract_mode_guards.txt
#
# Screenshots land in saves/shots/.
