## Issues & Resolutions

### **Issue 1: Out-of-Bounds Sprite Artifacts & Border Outlines**
* **Problem**: When importing custom sprite frames from different texture packages, color outlines and borders around sprite frames had visual artifacts (e.g., non-transparent outlines, mismatched scaling, or alignment issues).
* **Resolution**: Developed `scripts/merge_spritesheets.py` and `tools/outline-cleaner/clean_outlines.html` to programmatically strip dark borders, filter alpha values, and stitch individual grid cells into optimized sheets (`item.png` and `enemy_projectile.png`).

### **Issue 2: Audio Asset Failure Safety**
* **Problem**: In SFML, attempting to load a missing or corrupted audio file using `sf::SoundBuffer::loadFromFile()` would fail silently or throw exceptions at runtime, causing a crash when play is requested.
* **Resolution**: Implemented a fallback mechanism in [SoundManager::loadSound()](file:///Users/huynguyen/Documents/CS202-Cpp/SuperMarioGame/SuperMarioGame/src/Core/SoundManager.cpp). If an audio asset is missing, it dynamically synthesizes a basic 10ms beep waveform programmatically into an in-memory buffer (`m_fallbackBuffer`), ensuring safety against missing file crashes.
