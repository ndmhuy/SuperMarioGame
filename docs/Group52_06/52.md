## Issues & Resolutions

### **Issue 1: Coin Collected Increment Bug in Achievement Observer**
* **Problem**: When a player collected multiple coins simultaneously (such as a coin block dispensing 10 coins), the AchievementManager only registered a single increment of `m_coinsThisRun` because the EventBus observer was doing `m_coinsThisRun++` instead of reading the event data payload.
* **Resolution**: Modified the `CoinCollected` switch-case inside `AchievementManager::handleEvent()` to attempt an `any_cast<int>` on the event data, correctly accumulating the amount payload.

### **Issue 2: Aggregate sf::Vertex Initialization Compiler Error**
* **Problem**: Compiling with SFML 3.0.2 threw errors when instantiating `sf::Vertex` using parenthesis syntax (`sf::Vertex(...)`) due to the removal of overloaded constructors for aggregate types.
* **Resolution**: Replaced the constructors calls with brace bracket initialization syntax (`sf::Vertex{...}`) which satisfies aggregate type requirements for both SFML 2.x and 3.x.

### **Issue 3: Filled and Empty Star Size Mismatch in Star Coin HUD Indicators**
* **Problem**: When rendering empty and filled star icons to denote collected star coins, the filled stars appeared smaller than the empty stars because the empty stars had outlines while filled stars did not, causing a visual size mismatch.
* **Resolution**: Configured both empty and filled star shapes to have the exact same outline thickness and outline color settings in [HUD.cpp](file:///Users/huynguyen/Documents/CS202-Cpp/SuperMarioGame/SuperMarioGame/src/Graphics/HUD.cpp), ensuring consistent visual dimensions.

### **Issue 4: Star Coins Count Text Redundancy**
* **Problem**: The HUD originally displayed a text count for star coins, which was redundant and did not align with the `HudData` specification which only requires graphical indicators for the 3 individual star coins in a level.
* **Resolution**: Removed the text count representation and graphical icon at position X=260 from [HUD.cpp](file:///Users/huynguyen/Documents/CS202-Cpp/SuperMarioGame/SuperMarioGame/src/Graphics/HUD.cpp) and [Hud.hpp](file:///Users/huynguyen/Documents/CS202-Cpp/SuperMarioGame/SuperMarioGame/include/Graphics/Hud.hpp), strictly rendering the 3 individual collected flags.
