## Issues & Resolutions

### **Issue 1: Coin Collected Increment Bug in Achievement Observer**
* **Problem**: When a player collected multiple coins simultaneously (such as a coin block dispensing 10 coins), the AchievementManager only registered a single increment of `m_coinsThisRun` because the EventBus observer was doing `m_coinsThisRun++` instead of reading the event data payload.
* **Resolution**: Modified the `CoinCollected` switch-case inside `AchievementManager::handleEvent()` to attempt an `any_cast<int>` on the event data, correctly accumulating the amount payload.

### **Issue 2: Aggregate sf::Vertex Initialization Compiler Error**
* **Problem**: Compiling with SFML 3.0.2 threw errors when instantiating `sf::Vertex` using parenthesis syntax (`sf::Vertex(...)`) due to the removal of overloaded constructors for aggregate types.
* **Resolution**: Replaced the constructors calls with brace bracket initialization syntax (`sf::Vertex{...}`) which satisfies aggregate type requirements for both SFML 2.x and 3.x.
